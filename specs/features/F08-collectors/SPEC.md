# F08 — Catalog Fetch (`internal/catalog/fetch`)

Depends on: F02, F04, F07

## 1. Purpose

`internal/catalog/fetch` is the network layer of the catalog pipeline: it fetches model data from the two configured sources — models.dev (unauthenticated provider + benchmark catalogues) and Artificial Analysis (authenticated v2 API, plus the opt-in per-model public page scraper) — and returns typed, validated records for the F23 `catalog refresh` orchestration to merge and persist. It is a pure fetch library: no persistence, no providers.toml, no merge, no config files beyond the AA API key. All collectors return normalized data with hard, loud invariants (no silent fallbacks except the one documented 403 path); the security rule is that a credential can never appear in an error message, a redirect target, or a follow-up request.

## 2. Behaviour

1. **Package layout** (`docs/plan/annex-b-catalog-port.md §2`): `internal/catalog/fetch/modelsdev/` holds the two independent models.dev collectors — `provider.go` (`FetchModelsDevProviders`) and `benchmark.go` (`FetchModelsDevBenchmarks`) — in the same package but with a file-level isolation rule: `benchmark.go` MUST NOT reference any provider-file symbol (`ProvidersURL`, `ProviderModel`, `FetchModelsDevProviders`), enforced by a source-text test, mirroring the Python module split (`annex-b §2.3`). `internal/catalog/fetch/aa/` holds `api.go` (`FetchAAv2`), `fields.go` (AA benchmark fields), and `page.go` (`FetchAAPage`). There is **no `transport.go`** — the F04 `internal/httpkit` client is used directly (binding decision, supersedes annex-b §2.5).
2. **httpkit integration.** F08 imports `internal/httpkit` directly and constructs one client per collector family (`specs/features/F04-*/CONTRACTS.md` pin): models.dev uses `httpkit.NewClient()` with all defaults (10s timeout, 1 retry / 500ms backoff on 5xx+network only, 256 KiB max response); AA uses `httpkit.NewClient(httpkit.WithTimeout(20*time.Second))` via `AAV2Client()` — Decision D1 (deviation from Python's 20s-everywhere: models.dev stays at httpkit defaults since its payload is small and static). `SetAllowList` is set per-request to the exact target URL before every `Do`/`GetJSON` call (F04 enforces it as the first check).
3. **Retry deviation.** Python retries 429 twice (3 attempts total) with `Retry-After`-aware backoff (`annex-b §2.1`); the F04 pin is **4xx never retried, including 429** — a 429 surfaces immediately as `rate_limited`. This is an accepted deviation (Decision D2): it changes only error timing, never output bytes; the collector-level tests assert the 429 error carries the right code and is surfaced on the first attempt. Transport-level retry/TLS/redirect tests belong to F04's suite, not F08 (`annex-b §2.1` table is F04's spec).
4. **Redirect protection.** httpkit rejects ANY 3xx hard (zero followed hops, `redirect_refused`), and the allow-list is enforced before every request — the same key-leak protection as Python's redirect veto (`annex-b §2.1`). Collectors never follow redirects, so the API key cannot be replayed to a third-party host.
5. **models.dev provider catalogue** (`annex-b §2.3`): one unauthenticated GET to `ProvidersURL = "https://models.dev/api.json"` with default httpkit client; NO pagination. Records with `status == "deprecated"` are dropped (Python `_is_deprecated`); the rest map to `ProviderModel{Provider, ModelID, Name, Status, BaseModel, Reasoning bool, EffortLevels []string}`. `Name` is `identity.CleanModelName(record.name)`; `Reasoning` is whether the record exposes effort levels; `EffortLevels` is the sorted list of `reasoning_options[].values` normalized through F07 `ParseEffort` (`"none"` → `"default"` → `"high"` collapse — the values are a subset of `identity.ReasoningLevels`). The core testable function is `FetchModelsDevProvidersFrom(client *httpkit.Client, url string) ([]ProviderModel, error)`; the zero-arg `FetchModelsDevProviders()` wrapper is what F23 calls (no client param — Decision D3).
6. **models.dev benchmark catalogue** (`annex-b §2.3`): one unauthenticated GET to `BenchmarksURL = "https://models.dev/models.json"` (a DIFFERENT URL from providers — pinned by a test). `FetchModelsDevBenchmarks(selectedNames []string)` extracts **only** the caller-selected benchmark names (`{name: nil for name in selectedNames}` pre-seeded extraction, `annex-b §2.3` line 108 — the names come from `benchmarks.toml`; this is NOT a model-id filter). Effort scoping: `record["variant"]` is parsed per `annex-b §2.3` (regex ports of `(?P<effort>minimal|low|medium|high|xhigh|max)` variants; `"none"` → `"default"`); a record with no parseable variant yields Effort `""` (non-effort-scoped); duplicate resolution across records sharing `(benchmark name, effort)` is **always the maximum numeric score** (`annex-b §2.3` line 106 — the Python `BENCHMARK_HARNESS_PRIORITY` is dead code and MUST NOT be ported). Result: `BenchmarkRecord{CanonicalID, Name, Benchmarks []BenchmarkEvidence{Name, Score decimal.Decimal, Effort string}}` — one record per models.dev model, carrying only selected benchmark names. `FetchModelsDevBenchmarksFrom(client, url, selectedNames)` is the testable core. The benchmark collector must also fetch fine with empty `selectedNames` (returns records with empty evidence) — F23 decides exclusions; F08 has no F06 dependency (Decision D4).
7. **AA v2 API** (`annex-b §2.4`, `docs/plan/research/model-data-pipeline-spec.md §1.3`): `FetchAAv2(client *httpkit.Client, apiKey string) ([]AAModel, error)` with `PrimaryURL = "https://artificialanalysis.ai/api/v2/language/models"` and `FreeURL = PrimaryURL + "/free"`. Every request sends header `x-api-key: <key>` plus httpkit's default User-Agent (`which-model/dev`). Pagination: `?page=<n>` ascending from 1, envelope `{data: [...], pagination: {page, has_more, total_pages}}`, hard cap `MaxPages = 100` (exceeding → error; the pagination invariants of `pipeline-spec §1.3` — response `page` must equal the requested page, else hard error). Item shape (`pipeline-spec §1.3`): `slug`, `evaluations.{artificial_analysis_intelligence_index, artificial_analysis_coding_index, artificial_analysis_agentic_index, + AA_BENCHMARK_FIELDS}`, `performance.median_end_to_end_response_time_seconds`, `artificial_analysis_intelligence_index_cost.cost_per_task.total_cost`. Index/benchmark values are converted fraction×100 (multiply by 100, rounded to 2 decimals via `decimal.Round(2)`) and **highest-wins across a model's tau-variant records** (collector-converted before dedup); negative values are a hard error (never clamped).
8. **403-only free fallback** (`annex-b §2.4`, Main pin): when the primary endpoint returns a 403, exactly ONE retry of the whole pagination on `FreeURL` (same `x-api-key` header — the key is for AA's own free tier, not a downgrade of auth). The 403 signal is **typed**: `var he *httpkit.Error; errors.As(err, &he) && he.StatusCode == 403` — `httpkit.Error{Code, StatusCode int, Err}` from the F04 contract (pinned; `StatusCode == 0` for non-HTTP failures). Error message text is sanitized and is NEVER a contract — no string matching. A 401 is NOT retried and never falls back; it propagates as `unauthorized`. 429/5xx/network errors propagate as-is after httpkit's retry policy. `FetchAAv2From(client, apiKey, primaryURL, freeURL)` is the testable core.
9. **AA key resolution** (`annex-b §2.4`): `LoadAAAPIKey(repoRoot string) (string, error)` — environment variable `ARTIFICIAL_ANALYSIS_API` first, then `<repoRoot>/.env` (simple `KEY=VALUE` scanner: skip blank lines and `#` comments, strip one layer of matching surrounding quotes, duplicate key = hard error, unknown lines = hard error); if both are absent → hard error naming both (`missing ARTIFICIAL_ANALYSIS_API environment variable or .env entry`). No config-file key in F08 (graph F08 → F02, F04, F07 excludes F01); the historical `AA_API_KEY` config name is documented as an alias of the env var in CONTRACTS (Decision D5). Missing key is catalog-owned code `missing_api_key` (not in the global §1.6 table; F23 maps to exit 2). Errors never echo the key value.
10. **AA public page scraper** (`annex-b §2.4`): `FetchAAPage(client *httpkit.Client, slug string, requireFallbackCost bool) (*PageMetrics, error)` — unauthenticated GET to `https://artificialanalysis.ai/models/<slug>` (the html page), `httpkit.NewClient(httpkit.WithTimeout(20*time.Second), httpkit.WithMaxBytes(2<<20))` (2 MiB cap, Decision D6); NO custom headers. `currentModel` script-markers are extracted with `slug` matching the requested slug case-insensitively: `intelligenceIndexTimePerTask` (seconds) and `intelligenceIndexCostPerTask.cost.total` (USD, only read when `requireFallbackCost == true`). Zero matching markers → `(nil, nil)` (no error); MORE than one marker with unequal slugs → hard error; marker counts that disagree between the two fields → hard error (ambiguous data must never be guessed). `FetchAAPageFrom(client, slug, requireFallbackCost, url)` is the testable core.
11. **Typed errors and codes.** All collectors return `*fetch.Error{Code string, Err error}`; codes map to the global `Failure.Code` set (`specs/global/CONTRACTS.md §1.6`): httpkit errors map by `Error.Code` (`redirect_refused`→`redirect_refused`, `response_too_large`→`response_too_large`, `timeout`→`timeout`, `network`→`network`, `response_json`→`response_json`) and for HTTP-level failures by status: 401 → `unauthorized`, 429 → `rate_limited`, 5xx → `provider_status`, 403 → `access_denied` (surfaced only when the free fallback also failed). `missing_api_key` is F08's own code. Messages are sanitized: the API key NEVER appears in any error string, body preview, or URL echo (canary tests).
12. **`AAModel` shape** (`annex-b §2.4`): `AAModel{Slug string, IntelligenceIndex *decimal.Decimal, CodingIndex *decimal.Decimal, AgenticIndex *decimal.Decimal, MedianResponseSeconds *decimal.Decimal, CostPerTaskUSD *decimal.Decimal, Benchmarks map[string]decimal.Decimal}` — `Benchmarks` keyed by the **generated `benchmark:<name>`-style column names** of `AABenchmarkFields` (annex-b §2.4 verbatim; this is what F23 merges directly into raw CSV columns). Nil pointers = absent field in the record.

## 3. Error behaviour

- Collectors never return partial data with a non-nil error (all-or-nothing per source; the AA pagination loop aborts on the first page failure — no partial model list).
- Error → `Failure.Code` mapping for F23 is the table in `specs/features/F08-collectors/CONTRACTS.md §3`; exit codes follow `specs/global/SPEC.md §5` via F23.
- Sanitization invariants (canary-tested): no error string contains the API key; the free-fallback request carries the key only in the `x-api-key` header of the AA host (never in a URL, never after a redirect — redirects are refused); `.env` parse errors don't echo the key.

## 4. Decisions

| Decision | Value | Rationale |
|---|---|---|
| D1 Timeouts per family | models.dev = httpkit defaults (10s); AA v2 + page = 20s via `AAV2Client()`/`WithTimeout(20s)` | Python used 20s everywhere; models.dev payload is small/static and httpkit's default suffices; AA's pagination needs headroom (annex-b §2.1 table) |
| D2 429 retry dropped | No 429 retry; surfaces immediately as `rate_limited` | F04 pin (4xx never retried) supersedes Python's 2x429 retry; error-timing-only difference, recorded here and in annex-b §2.1 as a deviation |
| D3 No client params on public functions | `FetchModelsDevProviders()` / `FetchModelsDevBenchmarks(selectedNames)` zero-arg-on-client wrappers over `...From(client, url)` cores | F23-facing API stays clean; tests inject httptest servers via the `From` cores (SddCliCore confirmed this contract) |
| D4 No F06 dependency | models.dev benchmark collector does not apply `providers.toml` exclusions; F23 does | Graph F08 → F02, F04, F07; exclusions need the TOML loader, which F23 owns (annex-b §6.5) |
| D5 AA key sources | env `ARTIFICIAL_ANALYSIS_API` then `<repo root>/.env`; `AA_API_KEY` recorded as a historical alias only | Annex-b §2.4 + no F01 dependency; the assignment's config-key name is preserved as documentation |
| D6 Page scraper cap | 2 MiB response cap (httpkit `WithMaxBytes(2<<20)`), 20s timeout | HTML pages are larger than JSON; the cap is a hard invariant, not a soft truncation |
| D7 AA 403 discrimination | Typed: `errors.As(err, &httpkit.Error)` + `StatusCode == 403`; never message matching | Main pin (F04 `Error` gains `StatusCode int`); eliminates the Python `'HTTP 403' in str(error)` prototype wart; message text is not a contract |

## 5. Out of scope

- Orchestration: `Collect`/`CollectResult`, providers.toml loading and exclusions, merge, `csvstore` validation/atomic write, models.dev payload caching for `catalog providers` — all F23 (`internal/catalog` commands; F23 confirmed it assembles these from F08 primitives).
- Transport-level retry/backoff/TLS/redirect semantics and their tests (F04 `internal/httpkit` suite; annex-b §2.1 table is F04's spec).
- Config-file reads (`[catalog]`, `[scoring]`) — F01/F23; F08 reads only env + `.env`.
- Routing/usage integration, AA page persistence (`--add aa_page` opt-in wiring is F23's flag; F23 calls `FetchAAPage(client, slug, false)` — best-effort, `requireFallbackCost=false`).
- Offline scoring (F09 `internal/catalog/score`).
