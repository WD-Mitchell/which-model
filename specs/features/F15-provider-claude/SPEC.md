# F15 — provider-claude: Claude (Anthropic) subscription-usage adapter

## 1. Purpose

`internal/usage/provider/claude` is the Tier-1 adapter that reports Claude Code subscription usage allowance (the 5-hour and weekly rate-limit windows) from `GET https://api.anthropic.com/api/oauth/usage`. It is the Go port of `usage-allowance-checks/lib/claude.mjs` (91 lines), normalized into the canonical `usage.Window` contract, so its values stay diffable against the Node prototype's recorded fixtures. It self-registers a `usage.Descriptor` with ID `claude` (the ID `which-model usage claude` and `which-model pick` resolve).

## 2. Behaviour

1. **Credential chain is declarative.** The Descriptor's `Auth` chain is, in order: `AuthEnvVar` `WHICH_MODEL_CLAUDE_OAUTH_TOKEN` (annex-a §3.2 item 1, `docs/plan/annex-a-provider-matrix.md` §3.2), `AuthKeychainGeneric` service `"Claude Code-credentials"` (annex-a §3.2 item 2, gated to `runtime.GOOS == "darwin"` by F12), then ordered `AuthFile` entries over `~/.claude/.credentials.json` (dot-file first, annex-a §3.2 item 3) and `~/.claude/credentials.json` (annex-a §3.2 item 4) expressing the prototype's tolerant token shape `value.claudeAiOauth ?? value.oauth ?? value` × `accessToken ?? access_token` as one JSONPath entry per variant (`usage-allowance-checks-spec.md` §2.1, `claude.mjs:19-20`). The chain relies on F12's resolver rules: a missing JSONPath on an existing valid-JSON file yields "no candidate" and the chain continues; a missing file is skipped; malformed JSON is a hard `credential_json`; a token failing `security.ValidateOpaqueToken` is a hard `unsafe_credential` (F12 CONTRACTS, per F12 author confirmation).

2. **Fetch receives the chain-resolved `usage.Credential`.** F14 MUST invoke `Fetch` even when the chain resolved nothing (zero-value `Credential`). With `cred.Token == ""` the Fetch fails with `Failure{Code: "credential_file", Message: "Claude credentials were not found; sign in with Claude Code first."}` — the `.mjs` emits `credential_file` with exactly this message for a missing file (`claude.mjs:14-16`; global CONTRACTS §1.6: `credential_file` = missing/unreadable/oversized, exit class 5).

3. **File-sourced credentials are enriched, not re-resolved.** When `cred.Source == usage.AuthFile`, the Fetch re-reads the two declared file paths (dot-file first) to enforce the prototype's expiry check and broad-permission warning — the two behaviours `Credential` cannot carry (`claude.mjs:22-29`). Expiry: `expiresAt ?? expires_at`, number-or-`Date.parse`, seconds-vs-milliseconds heuristic `> 10_000_000_000`, expired when `<= now` → `Failure{Code: "expired_credential", Message: "The Claude access token is expired."}` (`claude.mjs:24-28`). Broad mode: any group/other permission bit set (F05 `security.HasBroadPermissions`) → write the verbatim warning `Warning: Claude credential permissions are broader than 0600; review them before continuing.` to stderr via the `log` package (the `.mjs`'s `warn` → `process.stderr`, `claude.mjs:59`). When the re-read finds nothing (file vanished), proceed with `cred.Token` and no warning. Env/keychain-sourced credentials (`cred.Source != usage.AuthFile`) have no local expiry or mode in the prototype and skip enrichment.

4. **Endpoint and headers are fixed constants.** `GET https://api.anthropic.com/api/oauth/usage` with exactly the five-header CodexBar set: `Accept: application/json`, `Authorization: Bearer <token>`, `Content-Type: application/json`, `anthropic-beta: oauth-2025-04-20`, `User-Agent: claude-code/2.1.0` (annex-a §3.2 "Usage request"; the fuller set supersedes prototype 1's tested 3-header subset per annex-a's explicit resolution; the version literal is the CodexBar fallback `2.1.0`, `codexbar-provider-survey.md:135`).

5. **Request discipline.** The request helper runs on the injected `*http.Client` (canonical `FetchFunc` signature, annex-a §5) and enforces: exact-URL allow-list via F05 `security.ValidateExactHTTPS` (mismatch → `endpoint_refused`), redirect hard-fail (a client copy with `CheckRedirect` returning `http.ErrUseLastResponse`; any 3xx → `redirect_refused`), body bounded via F05 `security.ReadResponseBounded` with `security.MaxResponseBytes` (`response_too_large`), JSON object parse (`response_json` on empty/unparseable), context deadline (`timeout`), transport failure (`network`) — the four invariants of `requestJson` (`usage-allowance-checks-spec.md` §1, `core.mjs:146-190`; global SPEC §6 items 1-3).

6. **Status mapping is fixed** (port of `statusError`, `core.mjs:192-200`): 401/403 → `unauthorized` (`Claude rejected the credential.`), 429 → `rate_limited` (`Claude rate-limited the usage request.`), any other non-200 → `provider_status` (`Claude usage is unavailable (HTTP <status>).`). Messages are the `.mjs` strings with the provider name `Claude`.

7. **Normalization ports `normalizeClaudeUsage`** (`claude.mjs:33-56`) over the snake_case response fields, in fixed order: `five_hour` → ID `5h`, Label `five hour`, `WindowMinutes 300` (hardcoded `sessionWindowMinutes = 5*60`, annex-a §3.2, survey:156); `seven_day` → ID `weekly`, Label `seven day`, `WindowMinutes 10080` (`weeklyWindowMinutes = 7*24*60`); `seven_day_sonnet` → ID `sonnet_7d`, Label `seven day Sonnet`, `WindowMinutes 10080`, `ModelScope ["sonnet"]`; `seven_day_opus` → ID `opus_7d`, Label `seven day Opus`, `WindowMinutes 10080`, `ModelScope ["opus"]`; `seven_day_oauth_apps` → ID `oauth_apps_7d`, Label `seven day OAuth apps`, `WindowMinutes 10080`; routines (try-key chain `seven_day_routines`, `seven_day_claude_routines`, `claude_routines`, `routines`, `routine`, `seven_day_cowork`, `cowork`; first present non-null object wins) → ID `routines_7d`, Label `seven day Routines`, `WindowMinutes 10080` (annex-a §3.2 response fields; CodexBar try-keys, survey:136-143). Per window: `UsedPercent = utilization ?? used_percent` (0..100 finite, string-or-number, port of `finitePercent`); the canonical `Window` has no remaining-percent field, so the renderer derives `100 - UsedPercent` (annex-a §3.2 mapping, `usage-allowance-checks-spec.md` §5); `ResetsAt = resetText(resets_at ?? reset_at)` (ISO string or epoch number, seconds-vs-ms heuristic, invalid → nil, port of `resetText`, `core.mjs:212-224`); `UsageKnown: true`; `Unit: percent`. A window source that is absent or not an object is skipped; a present-but-invalid `utilization`/`used_percent` skips the window (`claude.mjs:37-44`).

8. **Null `five_hour` must never render as 0%.** When `five_hour` is present-but-null or present-but-not-an-object, the Fetch emits the synthetic window `Window{ID:"5h", Label:"five hour", Unit:UnitPercent, Synthetic:true, UsageKnown:false}` with no `UsedPercent`/`Used`/`Limit`/`Remaining` — never a fabricated 0% used / 100% available reading. This is the documented CodexBar placeholder quirk (`codexbar-provider-survey.md:355`, annex-a §3.2 "Claude web (cookie) fallback" applied to the OAuth path). If `five_hour` is absent entirely, no synthetic window is emitted (prototype parity). `unsupported_response` (`Claude returned an unsupported usage shape.`) fires only when zero windows were produced and no synthetic applies.

9. **`extraUsage` and `limits` are ported per annex-a §3.2** (CodexBar fields the prototype does not consume; `codexbar-provider-survey.md:136-143`). `extraUsage` (object) → window ID `extra_usage`, Label `Extra usage`, `Unit: usd`, `Used = usedCredits` (finite ≥ 0), `Limit = monthlyLimit` (finite ≥ 0), `UsedPercent = utilization` (0..100), included when at least one of those three fields is valid; `isEnabled` is not consulted (presence of valid numbers governs). Each `limits[i]` (object) with valid `percent` (0..100) → window ID `limit:<slug(kind_group)>`, Label `group` when non-empty else `kind`, `UsedPercent = percent`, `ResetsAt = resetText(resetsAt)`, `ModelScope [scope.model.id]` when present; `isActive` is not consulted. `slug` = lowercase, runs of non-alphanumerics → `-`.

10. **Snapshot assembly.** `Snapshot{Provider:"claude", Windows, FetchedAt: now UTC, Source: SourceOAuth, Confidence:"live"}` (annex-a §3.2 "All windows ... Source = SourceOAuth"). `Account`/`Plan` stay empty (the prototype never verifies identity for Claude).

11. **Descriptor constants.** `Timeout: 15s` (annex-a §5 literal + §6 15-30s pattern), `CacheTTL: 60s` (annex-a §6 HTTP-fetched default), `Kind: KindSubscription`, `Tier: 1`, `DisplayName: "Claude"` (the `.mjs` report header name, `claude.mjs:63`, supersedes any longer product name so `formatUsageReport`-style text output stays verbatim). `Windows` descriptor list: `5h` (percent), `weekly`, `sonnet_7d`, `opus_7d`, `oauth_apps_7d`, `routines_7d`, `extra_usage` (usd) — `5h` is not Optional (always present, real or synthetic); the rest are Optional (emitted only when the response carries them). `init()` registers the Descriptor; a duplicate ID panics (registry contract, annex-a §5).

## 3. Error behaviour

All failures return `(zero Snapshot, *Error)` where `Error{Code, Message}` carries a global `Failure.Code` (§1.6 of `specs/global/CONTRACTS.md`) and a sanitized fixed message. Codes this feature emits: `credential_file`, `credential_json`, `unsafe_credential`, `expired_credential`, `endpoint_refused`, `redirect_refused`, `response_too_large`, `response_json`, `timeout`, `network`, `unauthorized`, `rate_limited`, `provider_status`, `unsupported_response`. No error message or log line ever contains credential material (global SPEC §6 item 5; canary-tested). The `.mjs` codes `identity_response`/`device_response` do not occur in this feature.

## 4. Decisions

| # | Decision | Value | Rationale |
|---|---|---|---|
| D1 | Tolerant credential shapes are ordered `AuthFile` entries (one JSONPath per variant), not resolver magic | 8 entries: `claudeAiOauth.accessToken`, `claudeAiOauth.access_token`, `oauth.accessToken`, `oauth.access_token`, `accessToken`, `access_token` × {dot-file, plain file} | F12 resolves "missing JSONPath → no candidate, continue"; matches `.mjs` `??` chains and both test fixtures (nested and flat, `usage-allowance.test.mjs` cases 1 and 4) |
| D2 | Fetch enriches file-sourced credentials by re-reading the two file paths | expiry check + broad-permission warning only when `cred.Source == AuthFile` | `Credential` cannot carry `expiresAt` or warning semantics; re-read is bounded (1 MiB, F05) and only on the file leg |
| D3 | Five request headers (CodexBar set), not the prototype's three | adds `Content-Type: application/json`, `User-Agent: claude-code/2.1.0` | annex-a §3.2 explicit resolution: the fuller set is the one verified in production |
| D4 | `User-Agent` version literal `2.1.0` (no auto-detection) | constant `claude-code/2.1.0` | Go port does not ship the `claude` binary; CodexBar's fallback version is the documented value (survey:135) |
| D5 | Null/non-object `five_hour` → synthetic `5h` window (`Synthetic:true, UsageKnown:false`, no percent fields); absent `five_hour` → no synthetic; zero windows otherwise → `unsupported_response` | assignment-mandated | "null five_hour MUST NOT render as 0%" — the CodexBar placeholder quirk (survey:355); absent-key parity with `.mjs`; fail-closed shape drift preserved |
| D6 | `remainingPercent` has no canonical field; renderer derives `100 - UsedPercent` | — | global CONTRACTS §1.4 `Window` is canonical; annex-d's text/JSON samples show only `used_percent` |
| D7 | Window labels are the `.mjs` labels verbatim (`five hour`, `seven day`, `seven day Sonnet`, `seven day Opus`, `seven day OAuth apps`); IDs from annex-a §3.2 (`5h`, `weekly`, `sonnet_7d`, `opus_7d`, `oauth_apps_7d`, `routines_7d`, `extra_usage`) | — | output diffability against the Node prototype (annex-d §2.1 sample shows `"id": "5h", "label": "five hour"`); annex-a's Label column is superseded where it duplicates IDs |

| D13 | Broad-permission warning via `log` (stderr) | only stderr side effect a Fetch may have | mirrors `.mjs` `warn` → `process.stderr` (claude.mjs:59); Snapshot has no warning channel |
| D14 | Opaque-token shape follows pinned F05 `security.ValidateOpaqueToken` (length 1..8192, single line, no control chars), superseding `assertOpaque`'s 8..16384 | identical `unsafe_credential` outcome | F05 is binding (Main pin); both reject whitespace/control characters, which is the security-relevant property |
| D15 | Missing credential file → `credential_file` (not `login_required`), exit class 5 | message verbatim from `claude.mjs:16` | global CONTRACTS §1.6 defines `login_required` as "no credential found, **no --login**"; Claude has no `--login` flow, and the `.mjs` emits `credential_file` |

## 5. Out of scope

- `claude-admin` (Admin API, `KindAPIKeyBilling`, org cost reports) — a separate Descriptor per annex-a §3.2; not the subscription surface.
- Claude web (cookie) fallback (`claude.ai/api/organizations`…) and its `SourceWeb` synthetic path — no cookie support in the prototype; the OAuth-path synthetic rule (D5) covers the assignment's null-`five_hour` requirement.
- Token refresh (`POST https://platform.claude.com/v1/oauth/token`) — the prototype never refreshes; expiry is fail-closed.
- Keychain resolution internals, `~`/env expansion, device-flow — F12's domain; this feature only declares the chain.
- Build-tag `nousage` stubbing — F21's domain (global SPEC §4); nothing in this feature requires it (DEPENDENCY-GRAPH §2 lists no `blocks` for F15).
- Text rendering of windows (`formatUsageReport` port) — F24's domain; this feature guarantees data-level parity.
